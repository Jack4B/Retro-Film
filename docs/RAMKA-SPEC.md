# Specyfikacja ramki

Wszystkie wymiary jako ułamki boku kwadratu **S** (początek układu: lewy górny róg).

| Element | Wartość |
|---|---|
| Marginesy boczne i górny | 0,05 S |
| Obszar zdjęcia | 0,90 S × 0,70 S (od y = 0,05 S do 0,75 S), dopasowanie bez kadrowania, wyśrodkowane |
| Środek podpisu (oś Y) | 0,825 S |
| Wysokość fontu podpisu | 0,075 S |
| Pasek EXIF (opcjonalny), środek | 0,925 S |
| Wartości EXIF | 0,026 S |
| Etykiety EXIF | 0,018 S |
| Układ EXIF | 4 kolumny (ISO, F, mm, S), cienkie separatory |

- Kolory ramki: biały, kremowy, czarny (kolor tekstu kontrastowy).
- Proporcje wyjścia: 1:1 lub oryginalne.
- Ta sama ramka dla całej serii. Bez znaków towarowych firm trzecich.
